GETTING STARTED

从一个具体的问题开始

  1. 登录，让探索有迹可循

    右上角注册或登录后，新提交的问题和结果会保存在「我的历史」。也可以匿名体验，离开前记得下载结果。

  2. 选择一种探索方式

    「深入研究」会先规划，再搜索并撰写报告；「快速问答」直接回答，必要时调用搜索工具。勾选「重新搜索最新资料」可跳过近期搜索缓存。

  3. 阅读答案，也检查来源

    研究完成后可以查看搜索计划、参考来源，复制或下载 Markdown 报告。历史任务中可以查看状态、阶段耗时和失败原因。

每次提问独立处理，不继承上一次对话。提交后请保持页面打开；刷新后可查询已保存的任务，但当前不支持后台续跑或取消。研究仅依据搜索返回的片段与摘要，未抓取网页全文。
