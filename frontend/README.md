# 网页研究助手「知序」

这是面向访客的最小网页入口：输入问题，选择「深入研究」或「快速问答」，阅读并导出结果。不需要登录，也不需要安装前端工具链。HTML、CSS、JavaScript 都由 Go 提供，浏览器与 API 使用同一个地址。

## 运行方式

先按根 README 启动 Python，再在 `backend/` 中运行 `go run .`，访问 **http://127.0.0.1:8080**。

不要直接双击 `index.html`，也不要只用普通静态文件服务器打开它；页面需要同源的 `/ping` 和 `/api/research`。修改 HTML、CSS、JS 后刷新页面即可；修改 Go 代码才需要重新启动 Go。服务器部署见 [部署说明](../deploy/README.md)。

## 文件与职责

| 文件 | 内容 | 常见修改位置 |
|---|---|---|
| `index.html` | 页面结构、两种模式、问题表单、报告/计划/来源标签、帮助弹窗 | 品牌名、标题文案、示例问题 |
| `assets/styles.css` | 暖白与陶土橙主题、桌面双栏、手机单栏、Markdown 排版、状态样式 | 颜色变量在文件开头，响应式规则在末尾 |
| `assets/app.js` | 表单状态、API 调用、结果展示、来源链接、复制与下载 | 核心请求在 `submitResearch`，结果入口在 `showResult` |
| `assets/favicon.svg` | 网站图标和品牌标志 | SVG 可直接修改颜色、形状 |
| `assets/icons.svg` | 本地 SVG 图标集合 | 按图标的 `id` 引用 |
| `assets/empty-state.svg` | 尚未提问时的纸张插图 | 纯 SVG，不依赖外部图片 |
| `assets/vendor/` | 固定版本的 Markdown 转换和 HTML 清洗库 | 版本、来源和许可证见 [第三方说明](assets/vendor/THIRD_PARTY.md) |

这些都是静态资源，没有 `npm install` 或 `npm run build` 步骤。部署时把 `frontend/` 随代码上传，Go 镜像会将它一起打包。

## 功能如何工作

1. **选择模式。** 页面默认选择 `research`，会经过 Planner → Searcher/Search Agent → Writer。`chat` 调用原来的问答 Agent，必要时使用工具。两者每次请求都独立，没有多轮对话记忆。
2. **输入问题。** 按 Unicode 字符计数，去掉首尾空白后允许 1～5000 个字符。点击示例只填入输入框，不直接发起模型调用。支持 `⌘+Enter` / `Ctrl+Enter`。
3. **发出请求。** `submitResearch` 使用 `fetch` 向同源 `/api/research` 发送 `{query, mode}`；等待期间禁用重复提交和编辑。
4. **等待结果。** 显示真实经过的时间。当前 API 一次返回全部结果，没有实时阶段事件，因此页面不展示虚构的阶段进度或百分比。问答在 140 秒、研究在 320 秒后结束浏览器等待，略长于 Go 的 130 / 310 秒预算。
5. **展示答案。** `showResult` 读取 `result`、`plan`、`search`。报告页展示 Markdown；计划页展示目标、每项搜索的目的、状态与摘要；来源页展示真实标题、地址和搜索片段。普通问答只显示回答页。
6. **处理资料缺口。** `search.status=partial` 时显示提示，计划页区分取得资料、暂无资料和搜索失败。搜索全失败或没有可用资料时展示错误，不把错误当作报告。
7. **复制、下载或重新提问。** 复制和 `.md` 下载保留原始 Markdown。浏览器不允许剪贴板写入时提示使用下载。点击「新研究」清空当前页面结果。

## 状态与错误

`setView` 管理四种界面：`empty`（尚未开始）、`waiting`（等待）、`success`（成功）、`error`（失败）。`setBusy` 单独负责锁定表单；无论成功或失败，`finally` 都会恢复输入。

- **400 / 413：** 输入不合法或请求过大，保留问题方便修改。
- **429：** 全局并发或每分钟请求数已满，读取 `Retry-After` 提示多久后重试。
- **502：** 模型、搜索或上游服务异常，展示简洁提示，不直接显示内部堆栈。
- **504 / 浏览器等待超时：** 提示缩小问题范围或稍后重试。
- **网络中断：** 提示检查网络；点击「重新尝试」会发起一个新请求，不会恢复旧任务。

右上角的「服务已连接」仅表示 Go 的 `/ping` 可访问，不能证明模型或 Tavily 的凭据有效。浏览器重新联网时会再次检查。

## Markdown 与来源安全

模型内容属于外部输入。`renderMarkdown` 先用 Marked 转为 HTML，再用 DOMPurify 过滤为只包含标题、段落、列表、表格、代码、引用与链接的内容。图片、脚本、表单、样式和事件属性不会进入报告；页面不会自动加载来源网站的图片。

来源标题、片段、查询词等通过 `textContent` 插入。链接只接受 `http://` 或 `https://` 的绝对地址，拒绝带用户名或密码的地址；新标签页打开时附加 `noopener noreferrer`。Go 还提供同源 CSP 等响应头，脚本、样式与字体不依赖公共 CDN。

真正的 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`TAVILY_API_KEY` 留在 Python 服务配置中，不放进前端。浏览器只知道当前网站的 API 地址。

## 当前边界

- 没有账号、数据库、历史列表、后台任务恢复或多轮对话。
- 结果只在当前页面内存中，刷新或关闭页面后消失；没有使用 `localStorage` 保存问题或报告。模型/搜索服务和服务端日志仍可能记录处理内容。
- 不支持取消服务端任务。关闭网页不等于立即停止 Python 工作流，也不保证停止产生 API 用量。
- 研究仍基于搜索片段和摘要，不主动读取网页全文，也不自动证明引用能支持所有结论。
- 所有访客使用同一组服务端 Key。Go 默认共享 2 个并发名额和每分钟 20 次请求限制；这不是个人配额或费用上限。
- 桌面使用双栏，窄屏改为单栏；标签页支持方向键/Home/End，帮助弹窗支持 Escape，减少动画偏好会关闭旋转动画。

以上不依赖 V3 数据库阶段。以后可以在现有页面基础上接入登录、历史任务和 SSE。
