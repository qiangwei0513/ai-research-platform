# 网页研究助手「知序」

网页支持注册登录、个人研究历史、任务详情，以及「深入研究」和「快速问答」。仍可匿名体验，不需要安装前端工具链。HTML、CSS、JavaScript 都由 Go 提供，浏览器与 API 使用同一个地址。

## 运行方式

按[根 README](../README.md#本地启动完整功能)启动数据服务、Python、Go API 和 Worker，访问 **http://127.0.0.1:8080**。

不要直接双击 `index.html`，也不要只用普通静态文件服务器打开它；页面需要同源的 `/ping`、`/api/research`、`/api/auth/*` 和 `/api/tasks/*`。账号与历史需要启动 MySQL，并在 Go 中启用 `MYSQL_DSN` / `JWT_SECRET`。修改 HTML、CSS、JS 后刷新页面即可；修改 Go 代码才需要重新启动 Go。服务器部署见 [部署说明](../deploy/README.md)。

## 功能如何工作

1. **选择模式。** 页面默认选择 `research`，会经过 Planner → Searcher/Search Agent → Writer。`chat` 调用原来的问答 Agent，必要时使用工具。两者每次请求都独立，没有多轮对话记忆。
2. **输入问题。** 按 Unicode 字符计数，去掉首尾空白后允许 1～5000 个字符。点击示例只填入输入框，不直接发起模型调用。支持 `⌘+Enter` / `Ctrl+Enter`。
3. **发出请求。** 登录用户先通过 `/health` 检查异步配置，启用后向同源 `POST /api/tasks` 发送 `{query, mode, fresh}`、JWT 和 `Idempotency-Key`。收到 202 后释放表单，可继续提问。匿名或服务端未启用队列时保留 `/api/research` 同步提交。勾选「重新搜索最新资料」时 `fresh=true`。
4. **等待结果。** 后台任务优先通过 fetch SSE 显示排队、规划、搜索计数、写作和尝试次数；成功事件到达后读取持久化报告。搜索计数包含已结束的成功、空结果和失败搜索，不显示估算百分比。关闭网页不取消任务；刷新会恢复最近关注的任务。旧服务没有 `task_events` 能力时退回每 5 秒查询。匿名同步模式仍等待完整结果，浏览器预算为问答 140 秒、研究 320 秒。
5. **展示答案。** `showResult` 读取 `result`、`plan`、`search`。报告页展示 Markdown；计划页展示目标、每项搜索的目的、状态、摘要、缓存使用情况和资料获取时间；来源页展示真实标题、地址和搜索片段。普通问答只显示回答页。
6. **处理资料缺口。** `search.status=partial` 时显示提示，计划页区分取得资料、暂无资料和搜索失败。搜索全失败或没有可用资料时展示错误，不把错误当作报告。
7. **查看个人历史。** 点击右上角「我的历史」，每页显示 8 条任务。点开任务可查看状态、提交/结束时间、任务编号、阶段耗时、每次尝试和失败原因；活跃异步任务可取消。成功任务可重新打开报告；「用此问题再研究」只填入表单，不立即调用模型。任务列表在窗口可见时每 5 秒刷新；活跃任务详情使用 SSE，切换任务、关闭窗口或退出时中止连接。阶段耗时记录来自执行结果，实时计数来自事件，两者分别显示。
8. **复制、下载或重新提问。** 复制和 `.md` 下载保留原始 Markdown。浏览器不允许剪贴板写入时提示使用下载。点击「新研究」清空当前页面结果。

## 账号操作

1. 右上角点击「登录 / 注册」，选择「注册」，填写邮箱、密码和确认密码；成功后自动登录。
2. 已有账号直接登录。密码使用 UTF-8 字节校验，限制 8～72 字节；不会存到浏览器存储。
3. 登录后再提交的问题才会自动保存；历史中可以找回之前完成的报告，匿名结果不会追加入库。
4. 点击右上角邮箱可查看登录有效期、打开历史或退出。JWT 只写入当前标签页的 `sessionStorage`，刷新保留，最长 24 小时；关闭标签页通常会清除，浏览器会话恢复行为取决于浏览器。没有长期刷新令牌。
5. 退出会清除本页的私有报告、问题和历史数据。待返回的旧请求不会再次显示其他账号的内容。
6. 登录过期或服务器返回 401 时提示重新登录，不会自动把原请求改为匿名研究。明确选择「继续匿名使用」后才允许匿名提交。

网页账号自行注册。部署配置中的 MySQL、Redis 密码和 `JWT_SECRET` 不是网站登录账号。

## 状态与错误

`setView` 管理四种界面：`empty`（尚未开始）、`waiting`（等待）、`success`（成功）、`error`（失败）。`setBusy` 单独负责锁定表单；无论成功或失败，`finally` 都会恢复输入。

- **401：** 登录过期需重新登录；登录表单中表示邮箱或密码错误。
- **409：** 邮箱已注册，可切换到登录。
- **503：** 数据服务不可用，提示稍后重试；不退回匿名提交。
- **400 / 413：** 输入不合法或请求过大，保留问题方便修改。
- **429：** 全局并发或每分钟请求数已满，读取 `Retry-After` 提示多久后重试。
- **502：** 模型、搜索或上游服务异常，展示简洁提示，不直接显示内部堆栈。
- **504 / 浏览器等待超时：** 提示缩小问题范围或稍后重试。
- **网络中断：** 异步提交响应丢失时，同一页面重试相同问题复用幂等键，避免创建两项任务；刷新后该键不保留，应先到历史检查。已接收的任务在后台继续，SSE 带上次事件编号自动重连，不重新提交研究。同步请求不具备这项幂等保证。

右上角的「服务已连接」仅表示 Go 的 `/ping` 可访问，不能证明模型或 Tavily 的凭据有效。浏览器重新联网时会再次检查。

## Markdown 与来源安全

模型内容属于外部输入。`renderMarkdown` 先用 Marked 转为 HTML，再用 DOMPurify 过滤为只包含标题、段落、列表、表格、代码、引用与链接的内容。图片、脚本、表单、样式和事件属性不会进入报告；页面不会自动加载来源网站的图片。

来源标题、片段、查询词等通过 `textContent` 插入。链接只接受 `http://` 或 `https://` 的绝对地址，拒绝带用户名或密码的地址；新标签页打开时附加 `noopener noreferrer`。Go 还提供同源 CSP 等响应头，脚本、样式与字体不依赖公共 CDN。

真正的 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`TAVILY_API_KEY` 留在 Python 服务配置中，不放进前端。浏览器只知道当前网站的 API 地址。

## 当前边界

- 已接入 V3/V4/V5/V6：账号、历史、后台任务、SSE、取消和失败尝试。尚未实现阶段断点续跑，Worker 中断后重新执行完整流程；网页重连仅恢复订阅。
- 匿名结果仅在当前页面内存中，刷新后消失；登录后提交的任务和报告存入服务端 MySQL。浏览器不使用 `localStorage` 保存报告，`sessionStorage` 保存登录信息，以及最近关注任务的 ID 与用户 ID（不保存问题或报告正文）。模型/搜索服务和服务端日志仍可能记录处理内容。
- 异步任务点击取消后撤销执行权，Worker 心跳检测后关闭 Python HTTP，Python 随之取消本地任务。关闭网页本身不会取消后台任务，已发给模型的调用可能仍计费。
- 研究仍基于搜索片段和摘要，不主动读取网页全文，也不自动证明引用能支持所有结论。
- 所有访客使用同一组服务端 Key。Go API 默认共享 2 个请求槽位、每分钟 20 次提交；Worker 默认每进程并发 2，异步提交每用户最多 3 个活跃任务。旧同步接口不提供这项每用户配额，多进程槽位会累加；这些都不是费用硬上限。
- 桌面使用双栏，窄屏改为单栏；标签页支持方向键/Home/End，帮助弹窗支持 Escape，减少动画偏好会关闭旋转动画。

## V6 连接与刷新恢复

- `fetch` 请求头携带 Bearer JWT；不用在 URL 中放凭据。`ReadableStream` 与流式 `TextDecoder` 处理跨网络分块的中文，按空行解析 SSE，而不是把一次 read 当成一次事件。
- 断线后按 2 / 4 / 8 / 15 秒上限退避，`Last-Event-ID` 请求补发；重复业务事件按序号丢弃，snapshot 用于校正当前视图。15 秒服务端心跳维持连接；客户端 45 秒没有字节会中断并重连。
- 401 结束会话；403/404 停止订阅并提示；409 清除过大的游标获取快照；429 等待。成功、失败、取消后停止订阅。关闭详情、退出、换题和离开页面也会回收连接。
- `zhixu.activeTask.v1` 仅记录当前任务 ID 和所属用户。刷新时先核对登录用户，再查询并订阅同一任务。已完成并展示的报告刷新后可从历史打开；只有已经收到 202 的任务才能自动保存恢复指针。
- 本页最多一个主任务订阅加一个历史详情订阅。列表不为每行创建 SSE；服务端单用户连接配额也不是全站跨实例配额。

V6 自动测试覆盖分块解析、中文 UTF-8、补发去重、请求头、401、空闲超时、恢复指针、退出中止和历史详情。2026-10-20 另以独立 API、Worker、Python 和隔离 MySQL/Redis 实测了网页登录、真实阶段帧、刷新恢复、搜索计数、报告/来源、取消；模型与搜索输出使用联调替身，未进行付费模型效果测试。
